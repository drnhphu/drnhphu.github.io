Gửi dữ liệuSend your data

Tải lên phiếu đã điền, kèm mã hồ sơ trong email gửi phiếu. File được lưu theo mã hồ sơ, không theo tên doanh nghiệp. Upload the completed template with the case code from the template email. The file is stored under the case code, not your company name.

Tải file lênUpload the file

Trước khi gửi, mở trang Kiểm tra trong phiếu: mọi dòng phải ghi "Đạt".Before sending, open the Check sheet in the template: every row should say "Đạt".

Mã hồ sơ có dạng KHQ-261122-AB12, nằm trong email gửi phiếu.The case code looks like KHQ-261122-AB12 and is in the template email.
Nhập đúng email đã nhận phiếu.Enter the email the template was sent to.
Chọn một file .xlsx, .xls hoặc .csv không quá 10 MB.Choose an .xlsx, .xls or .csv file of 10 MB or less.

Đã nhận dữ liệuData received

File đã được lưu theo mã hồ sơ . Email xác nhận đã gửi tới hộp thư đăng ký. Nhóm phân tích sẽ duyệt dữ liệu và liên hệ nếu cần làm rõ trước khi chạy phân tích.The file has been stored under case code . A confirmation has been sent to the registered email. The team will review the data and get in touch if anything needs clarifying before the analysis.

Chức năng tải lên đang tạm dừng. Hãy trả lời email gửi phiếu, hoặc gửi file tới drnhphu@gmail.com với tiêu đề có mã hồ sơ.Uploading is paused. Please reply to the template email, or send the file to drnhphu@gmail.com with your case code in the subject line.
